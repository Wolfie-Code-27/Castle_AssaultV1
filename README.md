# Castle Destruction Game

A 3D physics-based game where you fire cannonballs at destructible castles.

## Quick Start

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open your browser to the URL shown (usually http://localhost:5173)

## Controls

- **Angle Slider**: Adjust cannon angle (0-85°)
- **Power Slider**: Adjust shot power (10-50 m/s)
- **FIRE Button** or **Spacebar**: Fire cannonball
- **Mouse**: Rotate camera view
- **Scroll**: Zoom in/out

## What's Included

- Realistic physics using Cannon-es
- Shiny metallic cannonballs
- Destructible brick castle walls
- Realistic lighting and shadows
- Interactive cannon controls
